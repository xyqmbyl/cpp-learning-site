01 · OOP

类与对象：蓝图与实例

类（class）是模板，对象（object）是按模板造出来的具体东西。 类不占内存（严格说是类型信息），对象才占内存。这句话能解释初学者 80% 的困惑。 


#include <iostream>
#include <string>

class Student {
private:                              // 数据藏起来
    std::string name_;
    int         score_;

public:
    // 构造函数 + 初始化列表（比在函数体里赋值更高效）
    Student(std::string name, int score)
        : name_(std::move(name)), score_(score) {}

    // const 成员函数：承诺不修改对象状态
    int  getScore() const { return score_; }
    const std::string& getName() const { return name_; }

    // 提供受控的修改入口
    void setScore(int s) {
        if (s < 0 || s > 100) {
            std::cerr << "分数非法，已忽略： " << s << '\n';
            return;
        }
        score_ = s;
    }

    void print() const {
        std::cout << name_ << " : " << score_ << '\n';
    }
};

int main() {
    Student s1("小 C", 92);
    Student s2("小 A", 98);

    s1.print();
    s2.print();
    s1.setScore(200);        // 被拦截，分数不变 —— 这就是封装的价值
    s1.setScore(95);
    s1.print();
    return 0;
}
02 · RAII

构造、析构与 RAII —— C++ 最重要的设计思想

RAII = Resource Acquisition Is Initialization（资源获取即初始化）、 翻译成人话：把资源的生命周期绑定到对象的生命周期上，构造函数里拿资源，析构函数里放资源。 


#include <iostream>
#include <cstdio>
#include <vector>

// 反面教材：手动管理，中间任何一个 return / 抛异常都会泄漏
void bad() {
    int* buf = new int[1000];
    // ... 中途 return 或者抛异常 → delete[] 永远不会执行
    delete[] buf;
}

// 正面写法：把资源交给对象管理
class Buffer {
private:
    int*  data_;
    size_t size_;

public:
    explicit Buffer(size_t n) : data_(new int[n]), size_(n) {
        std::cout << "申请了 " << n << " 个 int\n";
    }

    ~Buffer() {                     // 离开作用域时一定被调用
        delete[] data_;
        std::cout << "自动释放了\n";
    }

    // 禁止拷贝：否则两个对象会指向同一块内存，析构时
double free
    Buffer(const Buffer&)            = delete;
    Buffer& operator=(const Buffer&) = delete;
};

int main() {
    {
        Buffer b(1000);
        // 这里无论怎么 return、怎么抛异常，b 的析构函数都会执行
    }   // → 作用域结束，自动释放

    std::cout << "------\n";

    // 标准库里的 RAII 例子：vector 自动管理它的堆内存
    {
        std::vector<int> v(10, 7);
        v.push_back(1);
    }   // → 不需要 delete，vector 自己在析构时释放

    // 智能指针：RAII 的直接应用
    {
        auto p = std::make_unique<int>(42);
        std::cout << *p << '\n';
    }   // → 不需要 delete，unique_ptr 析构时自动
delete
    return 0;
}
⚠️
三法则 / 五法则

如果你手动写了析构函数、拷贝构造函数、拷贝赋值运算符中的任意一个， 通常三个都要写（这就是「三法则」）。C++11 之后再加上移动构造和移动赋值，就是「五法则」。 更省事的做法是：尽量别自己管理裸资源，用 vector / string / 智能指针，让编译器生成默认版本。

03 · Polymorphism

继承与多态：一套接口，多种行为

多态解决的问题是：调用方只关心"你能做什么"，不关心"你具体是什么"。


#include <iostream>
#include <memory>
#include <vector>
#include <cmath>

class Shape {
public:
    virtual double area() const = 0;          // 纯虚函数：子类必须实现
    virtual void   describe() const {         // 普通虚函数：子类可选覆盖
        std::cout << "面积 = " << area() << '\n';
    }
    virtual ~Shape() = default;               // ★ 基类必须有虚析构函数：
};

class Circle : public Shape {
    double r_;
public:
    explicit Circle(double r) : r_(r) {}
    double area() const override { return 3.14159265358979 * r_ * r_; }
};

class Rectangle : public Shape {
    double w_, h_;
public:
    Rectangle(double w, double h) : w_(w), h_(h) {}
    double area() const override { return w_ * h_; }
};

int main() {
    // 用智能指针管理多态对象，避免手动 delete
    std::vector<std::unique_ptr<Shape>> shapes;
    shapes.push_back(std::make_unique<Circle>(2.0));
    shapes.push_back(std::make_unique<Rectangle>(3.0, 4.0));

    double total = 0;
    for (const auto& s : shapes) {
        s->describe();            // 多态：各自调用自己的 area()
        total += s->area();
    }
    std::cout << "总面积 = " << total << '\n';
    return 0;
}
🧩
为什么基类必须有 virtual 析构函数

Shape* p = new Circle(); delete p;
如果 ~Shape() 不是虚函数，只会调用基类析构， Circle 自己的资源不会被释放 → 泄漏。这是面试高频题，也是真实 bug 来源。

🎯
什么时候该用继承

只有满足「is-a」关系时才用继承、Circle is a Shape ✅； Stack is a Vector ❌（栈不是向量，是「用向量实现」），这种情况用组合。 经验法则（优先组合，谨慎继承）。

04 · Templates

模板：让一份代码适配多种类型

STL 全部建立在模板之上。理解模板，才算真正理解 STL 为什么能做到"一套算法，适配所有容器"。


#include <iostream>
#include <string>

// 函数模板：编译器为每种用到的类型生成一件
template <typename T>
T myMax(const T& a, const T& b) {
    return (a > b) ? a : b;
}

// 类模板：一个通用的 栈 
template <typename T>
class Stack {
private:
    std::vector<T> data_;
public:
    void push(const T& v) { data_.push_back(v); }
    void pop()             { data_.pop_back(); }
    T&   top()             { return data_.back(); }
    bool empty() const     { return data_.empty(); }
    size_t size() const    { return data_.size(); }
};

// 可变参数模板（C++11）：一次打印任意多个参数
template <typename... Args>
void printAll(const Args&... args) {
    ((std::cout << args << ' '), ...);   // C++17 折叠表达开
    std::cout << '\n';
}

int main() {
    std::cout << myMax(3, 7)       << '\n';   // T = int
    std::cout << myMax(2.5, 1.5)   << '\n';   // T = double
    std::cout << myMax<std::string>("abc", "abd") << '\n';

    Stack<int> st;
    st.push(1); st.push(2); st.push(3);
    std::cout << st.top() << " size=" << st.size() << '\n';

    printAll("现代", "C++", 2026, 3.14);
    return 0;
}
🔧
模板的坑：定义必须放在头文件里

模板不是真正的代码，编译器在看到具体类型时才会生成代码、 所以模板的定义（不只是声明）通常要写在 .h 里， 否则链接时会把 undefined reference。这是初学模板最常见的困惑。

05 · STL

STL 三大件：容器、迭代器、算法

你不需要背 STL 的所有接口，只需要记住三件事， 有哪些容器、迭代器怎么用、常用算法叫什么名字。剩下的随查随用。

📦

容器 Container

负责存数据。vector 是动态数组，map 是有序字典，unordered_map 是哈希表……选对容器，题目难度直接降一档。

🔗

迭代器 Iterator

容器与算法之间的桥梁。它像「泛化的指针」，让 sort 不关心你给的是数组、vector 还是 deque。

⚙️

算法 Algorithm

现成的通用操作：排序、查找、计数、去重、变换。写题时先问自己"这个有没有现成算法"。


#include <iostream>
#include <vector>
#include <map>
#include <unordered_map>
#include <set>
#include <algorithm>
#include <numeric>
#include <string>

int main() {
    // ---------- vector：动态数组，最常用，默认首选 ----------
    std::vector<int> v = {5, 3, 8, 1, 9, 3};
    v.push_back(7);
    std::sort(v.begin(), v.end());                 // 升序
    std::sort(v.begin(), v.end(), std::greater<int>());  // 降序

    // 去重标准三连（先排序 → unique → erase）
    std::sort(v.begin(), v.end());
    v.erase(std::unique(v.begin(), v.end()), v.end());

    int sum = std::accumulate(v.begin(), v.end(), 0);
    std::cout << "sum = " << sum << '\n';

    // ---------- map：有序字典（红黑树），遍历时指 key 升序 ----------
    std::map<std::string, int> ordered;
    ordered["apple"]  = 3;
    ordered["banana"] = 5;
    ordered["cherry"] = 1;
    for (const auto& [key, val] : ordered)         // C++17 结构化绑定
        std::cout << key << " -> " << val << '\n';

    // ---------- unordered_map：哈希表，平均 O(1)，刷题主动 ----------
    std::unordered_map<std::string, int> freq;
    std::string text = "the quick brown fox jumps over the lazy dog the end";
    std::string word;
    for (char c : text) {
        if (c == ' ') { freq[word]++; word.clear(); }
        else         { word += c; }
    }
    freq[word]++;
    std::cout << "the 出现 " << freq["the"] << " 次\n";

    // ---------- set / unordered_set：去重与存在性判断 ----------
    std::set<int> s = {3, 1, 4, 1, 5, 9, 2, 6};
    s.insert(7);
    std::cout << "size = " << s.size() << '\n';     // 自动去重（只保留一次）
    if (s.count(4)) std::cout << "4 在集合里\n";

    // ---------- 二分查找：只能用在已排序区间 ----------
    std::vector<int> a = {1, 3, 5, 7, 9, 11};
    auto it = std::lower_bound(a.begin(), a.end(), 7);   // 第一个 >= 7 的位置
    std::cout << "下标 = " << (it - a.begin()) << '\n';   // 3

    return 0;
}
💡
刷题时最高频的 8 个 STL 操作

sort · lower_bound / upper_bound · unique · accumulate · max_element / min_element · reverse · next_permutation · __gcd（GCC 内建：std::gcd）。 把这几个练熟，能省下大量手写代码的时间。

容器与算法复杂度速查

选错容器是"能过"和"超时"之间最常见的原因。下面这张表建议截图存手机里。

🔥
vector 扩容会导致迭代器失效

归 size() == capacity() 时再 push_back， vector 会申请一块2 倍（GCC）或 1.5 倍（MSVC）的新内存、拷贝旧元素、释放旧内存、 这意味着之前保存的指针、引用、迭代器全部失效。 如果你提前知道要存多少元素，用 v.reserve(n) 一次分配到位。

07 · Practice

阶段验收题单

从这一阶段开始，正式进入「边学边刷」的节奏。建议每天 1～3 题，坚持比数量重要。

🟡 面向对象练习

  1. 设计 Fraction 分数类，支持加减乘除、约分、比较、输出
  2. 设计 DynamicArray 模板类，实现 push_back / size / 下标访问 / 析构释放
  3. 用继承写一个 Shape 体系（圆、矩形、三角形），求总面积
  4. 设计 String 类，自己实现拷贝构造、赋值运算符（体会浅拷贝问题）
  5. 用 RAII 封装一个文件句柄类，保证 fclose 一定被调用

🔴 STL 练习（可直接投到 LeetCode）

  1. 两数之和 → 体会 unordered_map 把 O(n²) 降到 O(n)
  2. 字母异位词分组 → unordered_map<string, vector<string>>
  3. 前 K 个高频元素 → priority_queue + 哈希计数
  4. 数组中的第 K 个最大元素 → 分别用 sort、堆、快选实现，比较复杂度
  5. 合并区间 → 自定义比较器 + sort
  6. 区间和的个数 / 二分查找系列 → lower_bound 熟练度
