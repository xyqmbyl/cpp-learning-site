# Code Bloom · C++ 与算法学习路线

一个纯静态的 C++ / 算法学习网站：零依赖、零构建步骤，双击 `index.html` 就能看。
深色优先、克制的排版，没有任何第三方素材与 CDN。四个章节页内置**在线编程练习**，
代码送到真实在线编译器编译运行并自动判题（需要联网）。

## 起始页（封面）

打开 `index.html` 时先看到的是一个**只有标题的起始页**，向下滚动会像翻书一样把封面翻过去，
然后才是真正的正文：

- 封面**右上角**是工具条：「上传背景图」「移除背景」（没有背景图时自动隐藏），最右侧是主题切换图标。
  封面本身只有标题与副标题，不显示任何按钮文字标签。
- 封面背景默认是主题色渐变；点「上传背景图」可以选一张本地图片当背景，图片只存在你自己的
  浏览器里（`localStorage`，键 `cppq-cover-bg`），不会上传到任何服务器。
- 图片处理：小于 1.2 MB 的原样保存（保留 PNG 透明与 GIF 动图）；更大的会先用 canvas 逐级压缩
  （最长边 1920 → 1440 → 1080 → 760）到能存下为止；万一还是存不下，则只在本次会话生效，并会提示。
- 「移除背景」清掉自定义图，回到默认渐变。
- 右上角的太阳 / 月亮图标可以随时切换**深色 / 浅色主题**（存在 `cppq-theme`），刷新后仍然记住。
- 翻页效果：**一次下滑手势就整页翻过去**，不需要慢慢滚满一屏。封面以 `rotateX` 绕顶边掀起、
  同时轻微后退并压暗，正文用 smoothstep 淡入并回位；整段动画由 rAF 逐帧驱动（约 520ms，先快后慢）。
- 往下滑 = 翻进正文，往上滑 / 到顶再上滑 = 翻回封面；拖滚动条松手后也会自动吸附到最近的一侧，
  不会卡在半页。光标停在封面时按空格 / 方向键、触屏滑动超过 8px 同样能翻页。
- **一次手势只翻一次**：触控板／滚轮的惯性尾巴（时间上远长于动画本身）会被整段吃掉，
  直到用户停手 250ms 以上或反向重新落手才交还给浏览器。所以不会出现「翻一次、正文又被惯性推走一段」的连翻两次。
- 进入正文后封面那 38% 的占位会被**真的收掉**（`height: 0px`）并同步修正滚动位置，画面完全不动。
  于是「正文里随便滚一下，封面又冒出来、再被带着翻一次」这条路在结构上就不存在了。
- 回封面只认**本来就站在正文最顶上、并且重新落手**的那一次上滑（键盘 ↑ / PageUp、触屏在顶部往下拽同理）。
  从正文中间一路往上滑冲过头只会停在顶部，不会突然把封面拽出来——这样「上滑看更多」和「上滑回封面」不会打架。
- 翻页只在首页生效；进入正文后页面滚动完全交给浏览器，不做任何拦截（触控板双指缩放、横向手势也不受影响）。
- 尊重系统「减弱动态效果」设置：此时翻页退化为淡入淡出，不做 3D 旋转。
- 关掉 JavaScript 也不会白屏：`<noscript>` 会直接隐藏封面，正文照常显示。

只有首页有封面翻页；其余章节页保持普通的吸顶导航，避免每换一页都要翻一次。

## 使用方式

- 直接用浏览器打开 `index.html`；因为是纯静态，也可以放到任意二级路径下的静态服务器。
- 每章页面右侧/顶部有本页小目录，页面内所有图示都是手写内联 SVG，不依赖任何 CDN。
- 学习进度存在浏览器 `localStorage`（键 `cppq-progress`），主题存在 `cppq-theme`。
  换浏览器或清缓存后进度会重置。

## 自定义

- **换配色**：改 `assets/css/style.css` 顶部 `:root` 里的自定义属性即可；浅色主题的覆盖值在
  `[data-theme="light"]` 块里。
- **换起始页背景**：直接用页面上的「上传背景」按钮，不需要改代码；想写死默认图，在
  `style.css` 里给 `.cover-bg` 加一条 `background-image`。
- **改封面文字/按钮**：在 `index.html` 的 `<section class="cover">` 里改。

## 视频链接说明

页面中的视频入口统一使用 B 站视频直链
（形如 `https://www.bilibili.com/video/BVxxxx/`），点进去就是对应的那一支视频，
不经过搜索页。想换视频时，把对应链接里的 BV 号替换掉即可。

## 在线编程与自动判题

四个章节页内置了可以直接在浏览器里写的编程练习（「在线练」代码实验块）：

- **basics.html**：判断素数、数组求和与最大值
- **oop-stl.html**：两数之和、前 K 个高频元素
- **algorithms.html**：二分查找、判断回文（双指针）
- **advanced.html**：自定义比较器排序（std::sort + lambda）

工作方式：

- 每个练习块是一个 `<div class="code-lab">`，题目以 JSON 形式写在容器内的
  `<script type="application/json" class="lab-spec">` 里（题干、代码模板、测试用例、提示）。
  页面底部引入的 `assets/js/judge.js` 会自动扫描并渲染所有挂载点。
- 代码在**真实在线编译器**（Wandbox，gcc-head）上编译运行，需要联网；断网或超时会明确提示，
  不会假装通过。判定规则是逐用例比对标准输出（忽略行尾空白与末尾换行差异）。
- 提交结果会按用例展示通过 / 失败，编译错误会回显编译器报错；结果缓存在浏览器
  `localStorage`（键 `cj-cache-*`），同样只存在本地。
- 新增练习只需在页面里照抄一个 `code-lab` 块并填入题目 JSON（参考
  `_tools/judge-demo.html` 的示例与坏配置自检），无需改任何脚本。
