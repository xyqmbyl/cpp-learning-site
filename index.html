Roadmap

五阶段学习路径

按顺序走，不要跳。每个阶段都给了「大概要多久」和「学完能做什么」，方便你判断自己是不是真的学会了。

01

环境搭建：让第一行代码跑起来

约 1～2 天 · 难点：不是写代码，是装环境

安装编译器与 IDE，跑通 Hello, World， 学会「编译 → 链接 → 运行」这条链路，并配好调试断点。

  • Visual Studio 2026（使用 C++ 的桌面开发工作负载）
  • VS Code + MSVC / MinGW-w64 + CMake Tools
  • 搞懂 .cpp → .obj → .exe 与 include 路径
先做这一步含完整配置 JSON

进入环境搭建教程 →

02

C++ 语言基础：语法、类型与内存初体验

约 4～6 周 · 每天 1.5 小时

变量与类型、运算符与流程控制、函数、数组与字符串、指针与引用、结构体。 这一阶段的目标不是"记住语法"，而是能独立写出 100 行以内的小程序。

  • 编译流程与预处理、命名空间
  • 栈与堆、指针与引用、const 的正确用法
  • std::string 与 std::vector 的入门用法
含内存模型图解含可勾选清单

03

面向对象与 STL：从"能写"到"写得像样"

约 5～8 周

类与对象、封装继承多态、运算符重载、模板入门；然后是 STL 三大件 vector / map / algorithm。这一阶段结束后，你已经能刷大部分简单题了。

  • 构造 析构、拷贝与移动语义、RAII
  • 容器选型：什么时候用 unordered_map 而不是 map
  • 迭代器、仿函数、lambda、常用算法

04

数据结构与算法：真正的分水岭

约 8～12 周 · 建议配合刷题同步进行

复杂度分析 → 线性表 → 栈队列 → 树与堆 → 哈希 → 排序 → 查找、 然后进入算法思想：双指针、前缀和、二分、贪心、DFS/BFS、回溯、DP、图论。

  • 每学一个结构，立刻去对应题库刷 5～10 题
  • 坚持写题解：题解写不出来说明还没真懂
  • 建立自己的模板库（快排、二分、并查集、Dijkstra…）

How to learn

学习方法与避坑指南

同一份路线图，有人 4 个月能刷中等题，有人 1 年还在背语法——差的是方法。

✓ 这样做

  • 代码一定要自己敲。看懂视频 ≠ 会写，别开 2 倍速看完就过。
  • 每个知识点写一个小 demo。指针就写个交换函数，STL 就写个词频统计。
  • 每学一个数据结构就立刻刷题。学和练间隔超过 3 天，记忆衰减很快。
  • 写题解。用一句话说清「这题为什么这么做」，写不出来就是没懂。
  • 建立自己的模板库。二分、快排、并查集、Dijkstra，写顺手的版本就固定下来。
  • 用调试器而不是 printf。学会看调用栈和变量窗口，效率差好几倍。

❌ 别这样

  • 不要一上来就啃《C++ Primer》。它更像词典，适合有基础后回头精读。
  • 不要同时开 5 门课。选定一套主线课，其余当参考，学完再说。
  • 不要只刷 easy。正确配比大约是 easy 4 : medium 4 : hard 2。
  • 不要背题解。换个数据范围就不会了，说明学的是答案不是方法。
  • 不要跳过复杂度分析。它是判断"这个算法能不能过"的唯一工具。
  • 不要为了学 C++ 而学 C++。早点进入项目或刷题，语言只是工具。
💡
给完全零基础的一句话

前两周你会觉得"这也太简单了"，第三周会突然觉得"这也太复杂了"，第五周会觉得「好像也还行」。 这三段情绪是必经的，卡在第二段的人最多——撑过去就赢了一半。
