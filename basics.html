01 · Basics

先搞懂：你的代码是怎么变成程序的

这是最容易被跳过、却最能减少"神秘报错"的一节。看懂这张图，你能自己判断错误出在哪一步。

第一个能跑的完整程序


// hello.cpp —— 第一个程序
#include <iostream>      // 引入输入输出流
#include <string>

int main()               // 程序入口，返回值给操作系统
{
    std::string name;
    std::cout << "请输入你的名字：";
    std::cin >> name;

    std::cout << "你好，" << name << "！欢迎来到 C++ 的世界\n";
    return 0;            // 0 表示正常退出
}
📝
逐行理解，别复制完就赢

#include 是预处理指令（没有分号）：std 是标准库命名空间：<< 叫流插入运算符，不是"左移"。

三种编译方式，都要会


# 1) 最常用：直接编译成可执行文件
g++ -std=c++20 -O2 -Wall hello.cpp -o hello

# 2) 分步看中间产物（排错神器）
g++ -E hello.cpp -o hello.i     # 只做预处理
g++ -S hello.i -o hello.s       # 编译成汇编
g++ -c hello.s -o hello.o       # 汇编成目标文件
g++ hello.o -o hello            # 链接

# 3) MSVC（Visual Studio 自带的编译器）
cl /std:c++20 /EHsc /W4 hello.cpp
⚠️
务必加上 -Wall / /W4

警告是编译器免费给你的代码审查。不开警告，很多未初始化变量、有符号无符号比较的问题会拖到运行时才炸。

2.1 变量、类型与输入输出

先记住一件事：类型决定了这个变量占多少字节、能表示多大范围、能做哪些运算。溢出是初学者最常见的隐蔽 bug。


#include <iostream>
#include <climits>

int main() {
    int         a = 10;              // 通常 4 字节，约 ±21 亿
    long long   b = 9000000000LL;    // 至少 8 字节，竞赛里的默认整数类型
    double      c = 3.14159;         // 双精度浮点
    char        d = 'A';             // 单引号！本质是 1 字节整数
    bool        e = true;

    std::cout << b << ' ' << c << '\n';
    std::cout << "int 最大值 = " << INT_MAX << '\n';
    std::cout << "int 单 " << sizeof(int) << " 字节\n";

    // 整数除法会截断，想要小数必须有一个操作数是浮点
    std::cout << 7 / 2 << '\n';        // 输出 3
    std::cout << 7 / 2.0 << '\n';      // 输出 3.5

    return 0;
}
类型典型大小范围 / 说明什么时候用
int4 字节±2.1 × 10⁹下标、计数、一般整数
long long8 字节±9.2 × 10¹⁸求和、乘法、竞赛必备
double8 字节约 15～16 位有效数字实数计算（浮点有误差，别用 == 比较）
char1 字节-128 ~ 127单个字符、字符串元素
bool1 字节true / false条件判断结果
size_t8 字节，64 位无符号.size() 的返回类型，和它比较时注意符号

2.2 运算符与流程控制


#include <iostream>

int main() {
    // ---- 判断闰年：逻辑运算符的组合练习 ----
    int year = 2024;
    bool leap = (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0);
    std::cout << year << (leap ? " 是闰年  : " 不是闰年") << '\n';

    // ---- for：九九乘法表 ----
    for (int i = 1; i <= 9; ++i) {
        for (int j = 1; j <= i; ++j)
            std::cout << j << 'x' << i << '=' << i * j << (j == i ? '\n' : ' ');
    }

    // ---- while：辗转相除法求最大公约数 ----
    int x = 48, y = 18;
    while (y != 0) {
        int t = x % y;
        x = y;
        y = t;
    }
    std::cout << "gcd = " << x << '\n';   // 6

    // ---- switch：记得写 break，否则会"贯穿"执行下一个分放 ----
    int level = 2;
    switch (level) {
        case 1: std::cout << "新手\n"; break;
        case 2: std::cout << "进阶\n"; break;
        default: std::cout << "未知\n"; break;
    }
    return 0;
}
🔍
易错点：= 和 ==

if (a = 5) 在 C++ 里是合法的（把 5 赋给 a，然后判断非零），编译器通常只给个警告。开后 -Wall 会把这类问题变成显式告警。

2.3 函数、参数传递与递归

核心问题只有一个：参数是「复制一件」还是「传同一个东西」。


#include <iostream>
#include <string>

// 值传递：函数里改 n，外面的实参不受影响
void addOneByValue(int n) { n += 1; }

// 引用传递：函数里改 n，实参跟着可
void addOneByRef(int& n) { n += 1; }

// const 引用：既不拷贝（高效），又不允许修改（安全）—— 传大对象的标准写法
void printBig(const std::string& s) { std::cout << s << '\n'; }

// 递归：一定要有 终止条件"，否则栈溢出
long long factorial(int n) {
    if (n <= 1) return 1;          // 终止条件
    return n * factorial(n - 1);
}

int main() {
    int a = 10;
    addOneByValue(a);              // a 仍然是 10
    addOneByRef(a);                // a 变成 11
    printBig("引用传参不会发生拷贝");
    std::cout << factorial(10) << '\n';   // 3628800
    return 0;
}
传参方式写法是否拷贝能否修改实参用在哪
值传递void f(int n)是后小类型（int/double/char）
引用传递void f(int& n)后是需要"带回结果"
const 引用void f(const T& x)后后大对象只读传参（推荐默认）
指针传递void f(int* p)拷贝指针本身是（可空）需要表达 可能没有值

2.4 数组、字符串与 vector


#include <iostream>
#include <vector>
#include <string>
#include <algorithm>

int main() {
    // C 风格数组：长度固定，不检查越界（危险）
    int arr[5] = {5, 2, 8, 1, 9};
    std::sort(arr, arr + 5);                    // 排序：注意是首尾指针
    for (int i = 0; i < 5; ++i) std::cout << arr[i] << ' ';
    std::cout << '\n';

    // std::vector：长度可变，自动管理内存 —— 默认就用它
    std::vector<int> v = {3, 1, 4, 1, 5};
    v.push_back(9);                             // 尾部追加
    v.pop_back();                               // 尾部删除
    std::cout << "size = " << v.size() << '\n';

    // 范围 for：只读遍历的首选写法
    for (int x : v) std::cout << x << ' ';
    std::cout << '\n';
    for (int& x : v) x *= 2;                    // 加 & 才能修改元素

    // std::string：比 char[] 好用太多
    std::string s = "hello";
    s += " world";                              // 拼接
    s[0] = 'H';                                 // 下标访问
    std::cout << s << " 长度=" << s.size() << '\n';
    std::cout << s.substr(0, 5) << '\n';         // 子串 "Hello"
    return 0;
}
🌱
从今天起，用 vector 替代数组

除非你在写底层代码或做性能极致优化，否则 std::vector 几乎永远是更好的选择：它知道自己的长度、会自动扩容、越界在 debug 模式下还能被检测出来。

2.5 结构体：把相关的数据打包


#include <iostream>
#include <string>
#include <vector>
#include <algorithm>

struct Student {
    std::string name;
    int         score;
    int         id;
};

// 比较函数：按分数降序，分数相同时指 id 升序
bool cmp(const Student& a, const Student& b) {
    if (a.score != b.score) return a.score > b.score;
    return a.id < b.id;
}

int main() {
    std::vector<Student> cls = {
        {"小 C", 92, 3},
        {"小 A", 98, 1},
        {"小 B", 92, 2},
    };
    std::sort(cls.begin(), cls.end(), cmp);

    for (const auto& s : cls)
        std::cout << s.id << "  " << s.name << "  " << s.score << '\n';
    return 0;
}
03 · Memory

程序运行时的内存布局

这张图是整个 C++ 学习里最重要的图之一。后面讲指针、生命周期、new/delete、栈溢出、段错误，全都要回到它。


#include <iostream>

int  g_counter = 0;          // 全局区：程序启动到结束一直存在
static int g_static = 5;     // 静态区：同上，但只在当前文件可见

int main() {
    int  stackVar = 10;              // 栈区：离开作用域自动销毁
    int* heapVar  = new int(20);     // 堆区：必须手动 delete

    std::cout << g_counter << ' ' << stackVar << ' ' << *heapVar << '\n';

    delete heapVar;                  // 释放！忘记这行就是内存泄漏
    heapVar = nullptr;               // 置空，避免变成"悬垂指针"

    // ❌ 千万别这么写：返回局部变量的地址
    // int* bad() { int x = 1; return &x; }   // x 已销毁，指向非法内存

    return 0;
}
04 · Pointers

指针与引用：C++ 最劝退、也最值钱的一节

一句话理解指针：它本身是一个变量，只不过这个变量里存的是"另一个变量的地址"。 就像门牌号不是房子，但拿到门牌号就能找到房子。

指针的常用操作


#include <iostream>

int main() {
    int  a = 42;
    int* p = &a;          // p 保存 a 的地址

    std::cout << a     << '\n';   // 42
    std::cout << *p    << '\n';   // 42（解引用）
    std::cout << p     << '\n';   // 一个十六进制地址

    *p = 100;                     // 通过指针修改 a
    std::cout << a     << '\n';   // 100

    // 空指针：表示"不指向任何对象 
    int* q = nullptr;
    if (q) { /* 不会执行 */ }

    // 数组名会退化成指向首元素的指针
    int arr[3] = {1, 2, 3};
    int* head  = arr;             // 等价于 &arr[0]
    std::cout << *(head + 1) << '\n';   // 2
    return 0;
}

引用的常用场景


#include <iostream>
#include <vector>

// 交换两个数：引用版（对比指针版的 *x 到处飞）
void swap2(int& x, int& y) {
    int t = x; x = y; y = t;
}

// 引用必须绑定到已有对象，且绑定后不能换目标
int main() {
    int a = 1, b = 2;
    swap2(a, b);                  // 直接传，不用取地址
    std::cout << a << ' ' << b << '\n';   // 2 1

    int& r = a;                   // r 是 a 的别名，不是新变量
    r = 99;
    std::cout << a << '\n';        // 99

    // 范围 for 里加 & 避免拷贝，加 const 防止误改
    std::vector<int> v{1, 2, 3, 4, 5};
    for (const int& x : v) std::cout << x << ' ';
    std::cout << '\n';
    return 0;
}
对比项指针 T*引用 T&
是否可以为空可以，nullptr，不可以，必须绑定对象
能否重新指向可以不可以，一经绑定终身不可
是否需要解引用需要 *p不需要，直接用
是否有自己的地址有（指针本身也是变量）可 &r 得到的是被引用对象的地址
典型用途动态内存、可空语义、数据结构实现函数参数、避免拷贝、运算符重载
🚨
四个必须记住的指针错误
  • 野指针：int* p; 未初始化就用 → 指向随机地址。声明即初始化为 nullptr。
  • 悬垂指针：delete p; 之后继续用 p，或返回局部变量地址。
  • 内存泄漏：new 了却忘了 delete，程序跑久了内存越来越大。
  • 重复释放：对同一块内存 delete 两次 → 崩溃。释放后立刻置 nullptr。

报错信息（节选）类型真正的原因怎么放

unresolved external symbol		 链接期函数只有声明没有定义，或没把其他 .cpp 一起编译补上实现，或把源文件加入项目
segmentation fault / 0xC0000005 访问冲突 运行有解引用空指针 / 数组越界 / 栈溢出用调试器看崩溃时 p 的值和数组下标

答案莫名变成负数 逻辑int 溢出据 long long，乘法前先转 1LL *
浮点数比较不相等 逻辑0.1 + 0.2 != 0.3用 fabs(a - b) < 1e-9
